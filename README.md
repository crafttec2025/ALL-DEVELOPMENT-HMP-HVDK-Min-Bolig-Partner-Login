A centralized hub for tracking, managing, and resolving development bugs in real-time.

🧐 About the Project
This project was built to bridge the gap between reporting a problem and fixing it. It provides a streamlined interface for developers to stay updated on daily issues, ensuring that no bug falls through the cracks.

🌟 Key Features
Real-Time Updates: Get notified of new bugs and issues as they are reported.

Centralized Dashboard: A single source of truth where the entire team can view and manage every ticket.

Daily Status Tracking: Keep a pulse on project health with daily summaries of active vs. resolved issues.

Assignee Management: Easily delegate tasks to specific team members to ensure accountability.

🛠 Getting Started
Prerequisites

[e.g., Docker]

Installation
Clone the repository

Bash
git clone https://github.com/your-username/your-repo-name.git
Install dependencies

Bash
npm install
Configure Environment Variables
Create a .env file in the root directory and add your database/API credentials.

Start the development server

Bash
npm run dev
📈 Usage
Once the app is running, you can:

Create a Ticket: Fill out the title, description, and severity.

Assign a Developer: Use the dropdown to delegate the bug.

Track Progress: Update the status from Open to In Progress to Resolved.

Tip: Use the "Daily View" filter to see only the issues reported in the last 24 hours.
